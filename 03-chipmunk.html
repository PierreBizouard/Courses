Voix de chipmunk

Enregistre ta voix, puis lis-la plus vite ou plus lentement. La hauteur et la durée sont liées : accélérer un son le rend plus aigu et plus court. Le spectre montre tout ce qui se décale.

Aucun son pour l'instant. Enregistre jusqu'à 8 secondes, par exemple « aaaa » ou une phrase.
×1,00vitesse de lecture
0 demi-tondécalage de hauteur
…durée de lecture
Lance la lecture à ×1, clique sur « Mémoriser la référence » (courbe grise), puis déplace la vitesse.
À essayer
  • À ×2, chaque pic du spectre se retrouve exactement deux fois plus haut en fréquence : une octave de plus. À ×0,5, une octave de moins.
  • Passe à l'axe logarithmique : multiplier une fréquence par un facteur revient à décaler toute la courbe vers la droite, sans la déformer.
  • Regarde la durée : à ×2, le son dure deux fois moins longtemps. Impossible de changer la hauteur sans changer la durée avec cette méthode.
  • Question pour la classe : comment un logiciel d'autotune corrige-t-il une note trop basse sans accélérer la voix ? (Réponse en page 5.)
Ouvrir le capot : le code

Un son numérique est une liste de nombres, accompagnée d'une fréquence d'échantillonnage qui dit combien de nombres on lit par seconde. Lire la même liste plus vite multiplie toutes les fréquences et divise la durée.

// JavaScript (cette page)
const lecteur = ctx.createBufferSource();
lecteur.buffer = enregistrement;
lecteur.playbackRate.value = 1.6;     // 1,6 fois plus vite
lecteur.connect(ctx.destination);
lecteur.start();

// décalage en demi-tons : 12 * log2(1.6) = +8,1 demi-tons
# Python
from scipy.io import wavfile
fs, x = wavfile.read("voix.wav")
wavfile.write("chipmunk.wav", int(fs * 1.6), x)   # mêmes nombres, lus 1,6 fois plus vite

# Autre version : on garde fs et on saute des échantillons (rééchantillonnage)
import numpy as np
r = 1.6
y = np.interp(np.arange(0, len(x) - 1, r), np.arange(len(x)), x)
wavfile.write("chipmunk2.wav", fs, y.astype(x.dtype))
