Quelle note chantes-tu ?

Une voix chantée est presque périodique : elle se répète toutes les T secondes. L'autocorrélation compare le signal à lui-même décalé dans le temps, et le décalage qui lui ressemble le plus donne T, donc la hauteur f = 1/T. C'est la première brique d'un autotune.

À essayer
  • Chante une note tenue, « aaaa » : une courbe d'autocorrélation avec des pics réguliers, un pic principal net, et la jauge qui se stabilise.
  • Chante en glissant du grave à l'aigu : la jauge traverse toutes les notes, et le décalage T se raccourcit.
  • Chante faux volontairement : le facteur de correction indique de combien l'autotune devrait multiplier la hauteur. Il vaut 1 quand tu es juste.
  • Parle ou chuchote : la périodicité est faible, la netteté chute et plus aucune note n'est affichée.
  • Compare avec la page 3 : accélérer la lecture applique aussi un facteur sur la hauteur, mais en changeant la durée. Un vrai autotune applique le facteur sans changer la durée.
Ouvrir le capot : le code

On calcule la ressemblance du signal avec lui-même décalé de τ échantillons, pour tous les décalages possibles de voix (de 70 Hz à 1000 Hz). Le décalage du premier grand pic est la période.

// JavaScript (cette page) : une version normalisée de l'autocorrélation
for (let tau = tauMin; tau <= tauMax; tau++) {
  let r = 0, m = 0;
  for (let j = 0; j < W; j++) {
    r += x[j] * x[j + tau];                  // produit du signal et du signal décalé
    m += x[j]*x[j] + x[j + tau]*x[j + tau];
  }
  nsdf[tau] = 2 * r / m;                     // entre -1 et 1 : 1 = identique
}
// le premier grand pic donne la période T = tau / fs, donc f = fs / tau
// note = 69 + 12 * log2(f / 440) ; écart = (note - round(note)) * 100 centièmes
# Python (même idée, version simple)
import numpy as np
from scipy.io import wavfile

fs, x = wavfile.read("voix.wav")
x = (x[:, 0] if x.ndim > 1 else x)[:4096].astype(float)
r = np.correlate(x, x, "full")[len(x) - 1:]            # autocorrélation r[tau]
tmin, tmax = fs // 1000, fs // 70
tau = tmin + np.argmax(r[tmin:tmax])
f0 = fs / tau
midi = 69 + 12 * np.log2(f0 / 440)
print(f"{f0:.1f} Hz, écart {100 * (midi - round(midi)):+.0f} centièmes")
