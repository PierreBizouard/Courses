Voix de robot : la modulation en anneau

On multiplie la voix par une sinusoïde. Chaque fréquence f de la voix donne deux fréquences : f − fc et f + fc, où fc est la fréquence de la sinusoïde. Les rapports entre harmoniques sont détruits, et la voix devient métallique.

Mode micro en direct : mets un casque, sinon le haut-parleur renvoie le son dans le micro (effet Larsen, sifflement).

À essayer
  • Source sinus 440 Hz, porteuse 100 Hz : deux pics à 340 Hz et 540 Hz, et plus rien à 440 Hz. Les traits pointillés indiquent la prédiction.
  • Descends la porteuse sous 20 Hz avec la voix : le volume pulse, c'est un trémolo. Monte à 30 Hz : le son devient rugueux (le côté « Dalek »). Au-dessus de 100 Hz : voix de robot métallique.
  • Bascule entre « Son d'origine » et « Modulation en anneau » sans arrêter la lecture : l'oreille reconnaît la voix, mais plus la hauteur.
  • Une porteuse à 5 Hz ne décale pas le spectre de façon audible mais fait varier le volume 5 fois par seconde.
Ouvrir le capot : le code

Un nœud de gain multiplie le signal par sa valeur. Si on branche la sinusoïde sur le paramètre « gain », le signal est multiplié par la sinusoïde. Math : cos(a)·cos(b) = ½[cos(a−b) + cos(a+b)], d'où les deux pics.

// JavaScript (cette page)
const porteuse = ctx.createOscillator();     // sinusoïde de fréquence fc
porteuse.frequency.value = 100;

const anneau = ctx.createGain();
anneau.gain.value = 0;                       // le gain vaut 0 + porteuse(t)
porteuse.connect(anneau.gain);

voix.connect(anneau);                        // sortie = voix(t) * cos(2π fc t)
anneau.connect(ctx.destination);
porteuse.start();
# Python (sur un fichier enregistré)
import numpy as np
from scipy.io import wavfile

fs, x = wavfile.read("voix.wav")
x = (x[:, 0] if x.ndim > 1 else x).astype(float)
t = np.arange(len(x)) / fs
y = x * np.cos(2*np.pi*100*t)                # porteuse à 100 Hz
y = (y / np.abs(y).max() * 32000).astype(np.int16)
wavfile.write("robot.wav", fs, y)
