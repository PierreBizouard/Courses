Spectrogramme en direct

Le spectre montre un instant. Le spectrogramme empile les spectres au fil du temps : l'axe horizontal est le temps, l'axe vertical la fréquence, la couleur le niveau. C'est l'image du son.

Survole l'image pour lire une fréquence.
À essayer
  • Le balayage dessine une droite en échelle linéaire et une courbe en échelle logarithmique. Une oreille entend les notes en échelle logarithmique.
  • Dis les voyelles a, e, i, o, u à la suite : les bandes horizontales brillantes (les formants) se déplacent, alors que ta hauteur reste la même.
  • Chante une note qui monte : les lignes horizontales des harmoniques montent ensemble, en éventail.
  • Prononce « ch », « s », « t » : les consonnes sont du bruit, étalé sur beaucoup de fréquences.
  • Fais claquer tes doigts : un trait vertical, car un son bref contient toutes les fréquences.
Ouvrir le capot : le code

À chaque image, on lit le spectre, on le colore, et on le dessine comme une colonne de pixels sur le bord droit. Le reste de l'image est décalé vers la gauche.

// JavaScript (cette page)
analyseur.getFloatFrequencyData(db);              // un spectre = une colonne
for (let y = 0; y < hauteur; y++) {
  const f = fmax * (1 - y / hauteur);             // fréquence de cette ligne de pixels
  const niveau = db[Math.round(f / (fs / fft))];  // niveau en dB à cette fréquence
  const t = (niveau - plancher) / (plafond - plancher);
  pixel[y] = couleur(t);                          // du noir au jaune
}
g.drawImage(canvas, -dx, 0);                      // décale l'image vers la gauche
g.putImageData(colonne, largeur - dx, 0);         // ajoute la nouvelle colonne
# Python (sur un fichier enregistré)
import numpy as np, matplotlib.pyplot as plt
from scipy.io import wavfile
from scipy.signal import spectrogram

fs, x = wavfile.read("voix.wav")
x = x[:, 0] if x.ndim > 1 else x
f, t, S = spectrogram(x, fs, nperseg=2048, noverlap=1536)
plt.pcolormesh(t, f, 10*np.log10(S + 1e-12), shading="auto", cmap="inferno")
plt.ylim(0, 5000); plt.xlabel("Temps (s)"); plt.ylabel("Fréquence (Hz)")
plt.colorbar(label="Niveau (dB)"); plt.show()
