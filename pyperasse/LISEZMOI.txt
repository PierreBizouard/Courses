Pyperasse & Cie : la version à distribuer

Ce dossier contient tout le jeu. Deux façons de l'utiliser.

1. Sur l'ordinateur, sans rien installer
   Double-cliquer sur index.html. Le jeu s'ouvre dans le navigateur.
   Il faut internet seulement pour les polices d'écriture : sans internet,
   le jeu marche avec des polices de secours.
   On peut copier ce dossier sur une clé USB ou sur le réseau du lycée.

2. En ligne, sur GitHub Pages
   a. Sur github.com, créer un nouveau dépôt PUBLIC (par exemple « pyperasse »).
      Sur un compte gratuit, GitHub Pages ne marche qu'avec un dépôt public.
   b. Dans le dépôt : « Add file » puis « Upload files ». Glisser TOUT le
      contenu de ce dossier (index.html, fichiers.js, les dossiers assets et fiches),
      pas le dossier lui-même. Valider avec « Commit changes ».
   c. Settings, puis Pages. Source : « Deploy from a branch », branche « main »,
      dossier « / (root) ». Enregistrer.
   d. Une ou deux minutes plus tard : https://VOTRE-NOM.github.io/pyperasse/

Adresses utiles (à ajouter à la fin de l'adresse du jeu)
- ?prof : tous les niveaux ouverts et les codes visa de n'importe quel badge.
- ?raz : efface la progression enregistrée sur ce poste.

Progression des élèves
Elle est gardée dans le navigateur du poste. Pour reprendre ailleurs,
l'élève tape son badge puis le dernier code visa de sa fiche dans la case
« Code de niveau ».

Fiches élèves (dossier fiches)
- Fiche-1-Premier-jour.pdf : niveaux 1.1 à 1.5 et dossier rouge 1.R.
- Fiche-2-Les-casiers.pdf : niveaux 2.1 à 2.5 et dossier rouge 2.R.
À imprimer en A4. L'élève y note ses réponses et ses codes visa.
Les corrigés ne sont pas dans ce dossier : il est destiné aux élèves.
