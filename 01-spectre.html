Spectre en direct

Un son est une somme de sinusoïdes. Le spectre indique quelles fréquences sont présentes et avec quelle force. Chante, siffle, parle, puis compare avec des sons purs générés par l'ordinateur.

À essayer
  • Sinus à 440 Hz : un seul pic. Le signal du haut est une vague régulière dont la période est 1/440 s.
  • Passe au signal carré, puis à la dent de scie : des pics apparaissent aux multiples de la fréquence. Ce sont les harmoniques, et ce sont elles qui donnent le timbre.
  • Chante « aaa » puis « iii » sur la même note : la hauteur ne bouge pas, la forme du spectre change.
  • Siffle : un pic net. Dis « ssss » : un spectre étalé, proche d'un bruit.
  • Change la taille de la FFT : plus elle est grande, plus la résolution en fréquence est fine, mais plus le spectre est moyenné sur une longue durée.
  • Pour une voix, le pic le plus haut n'est pas toujours la fondamentale. La page 5 mesure la hauteur autrement.
Ouvrir le capot : le code

Tout le calcul de la transformée de Fourier est fait par le navigateur. Il reste à lire le résultat et à le dessiner.

// JavaScript (cette page)
const ctx = new AudioContext();
const analyseur = ctx.createAnalyser();
analyseur.fftSize = 8192;                    // nombre d'échantillons analysés

const flux = await navigator.mediaDevices.getUserMedia({ audio: true });
ctx.createMediaStreamSource(flux).connect(analyseur);

const db = new Float32Array(analyseur.frequencyBinCount);
analyseur.getFloatFrequencyData(db);         // niveau en dB pour chaque fréquence
// la case i correspond à la fréquence  i * ctx.sampleRate / analyseur.fftSize
# Python (même idée, sur un fichier enregistré)
import numpy as np, matplotlib.pyplot as plt
from scipy.io import wavfile

fs, x = wavfile.read("voix.wav")
x = x[:, 0] if x.ndim > 1 else x           # un seul canal
N = 2**14
X = np.abs(np.fft.rfft(x[:N] * np.hanning(N)))
f = np.fft.rfftfreq(N, 1/fs)

plt.plot(f, 20*np.log10(X + 1e-9))
plt.xlim(0, 5000); plt.xlabel("Fréquence (Hz)"); plt.ylabel("Niveau (dB)")
plt.show()
